What is this website?

This site is fully designed by me, Ashley Manser, as a repository of my coding projects that I have accumulated. The projects vary from C++ GPU based fluid and airflow simulations to Python machine learning programs. I limit the use of AI as much as possible however many of these used some form of chatbot to help ease the learning curve.

Section Heading

All the HTML, JS, CSS and setup for this website were done by me. If you scroll down, you will find all the projects split into categories based on how they are run. These were all programs before I put them on here, so it is very likely that some (if not all) have errors from porting them over. If you do find any, please email me at ashmanser7@gmail.com saying what happened. Similarly, these projects have all been optimized in their original code but may not run as well in their browser form.

What are the projects

I started making these in my later years of high school just for a bit of coding experience and it has been a persistent hobby ever since. They are also a great way to flex some maths muscles, and I would highly recommend trying to make anything here. I enjoy making all of these, I hope you enjoy them too. If you have any suggestions for other projects I should do I would be thrilled to hear so, again, just email me.

How it works

All python projects just run with web python which is relatively simple. The OpenGL and GLSL GPU projects are compiled with Emscripten. The code is all on my Github. This site works by loading an edited (and for C++ compiled) version of the code and then running it in a canvas however the original version that was not designed for this website is also on each repository.
